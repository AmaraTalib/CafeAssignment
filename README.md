# Hanami Hour 🌸

A cafe website developed as part of a Web Development course assignment.

## About the Project

Hanami Hour is a simple cafe website designed to showcase a cafe's atmosphere, menu, and customer experience through a clean and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Cafe homepage
- Menu section
- Responsive website design
- Interactive elements
- Customer feedback form with JavaScript validation

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Project Type

Academic Assignment – Web Development
